# Strict-Stage Research

> Domain status: active strict graph substrate plus controlled and transitional
> studies.

Strict-stage work uses confirmed iterations from the selected positive-spine
field as operands, records speculative outputs, and does not operate on those
outputs unless the field rule later confirms them.

[Stage-Indexed Modulus of One Universe](STAGE_INDEXED_UNIVERSE_NOTE.md) records the core
framing. It is not a claim that the positive spine is the full signed
operator-fan field.

## Domain Rule

The SQLite graph corpus is preferred for current evidence because it preserves
nodes and edge occurrences. Older node-summary or saved-ledger work remains
useful as a bounded witness, but it cannot be promoted by wording. Its program
card must say whether the source ledger, derived report, and graph-native
reproduction exist.

The current large local corpora are governed by the
[corpus inventory](../experiments/CORPUS_INVENTORY.md), not by example
paths in older notes.
