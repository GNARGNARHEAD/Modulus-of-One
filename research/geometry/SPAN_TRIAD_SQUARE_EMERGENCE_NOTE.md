## Precondition: The Operator Fan

Span, triad, and square language is downstream of the first Modulus of One asymmetry. The
system is not born as the positive spine:

```text
1 + 1 -> 2
1 - 1 -> 0
1 * 1 -> 1
1 / 1 -> 1
```

Modulus of One reading:

```text
2:
  expansion / successor span

0:
  cancellation / first crossing

1:
  preserved identity through multiplication and division
```

These motifs study expansion and self-relation within the same operation
field. They must not erase the cancellation side.

## Early Motifs And Their Stages

These are related motifs, not a sequence of prerequisites. In an unfiltered
positive-spine field:

| Stage | Witnessed structure |
| --- | --- |
| `U1` | The full first fan: expansion to `2`, cancellation to `0`, and self-product/self-ratio returning `1`. |
| `U2` | Counted confirmation of `2`; `2*2 -> 4` and `2+2 -> 4`; `1+2 -> 3`. |
| `U3` | Counted confirmation of `3`; return witnesses `3-2 -> 1` and `3-1 -> 2` complete the additive triad below. |
| `U4` | Counted confirmation of `4`, whose square witness was already recorded at `U2`. |

Repeated self-products support inspection of a square branch. A square-like
geometric form is a further interpretation of that repetition.

## First Span

The first span is not a Euclidean line.

The expansion witness first records a relational result at `U1`; counted
recurrence confirms that result at `U2`:

```text
1 + 1 -> 2
```

Modulus of One reading:

```text
1:
  immediate certainty

2:
  expansion result at U1; counted recurrence confirms it at U2

1 -> 2:
  first successor span / first adjacency witness
```

The line-like reading is a later shadow of repeated adjacency:

```text
1 -> 2 -> 3 -> 4 -> ...
```

with the repeated relation:

```text
n + 1 -> n+1
```

## First Triad

The first triad is not a Euclidean triangle.

It is the first three-point additive closure frame:

```text
1 + 1 -> 2
1 + 2 -> 3
3 - 2 -> 1
3 - 1 -> 2
```

Modulus of One reading:

```text
1,2,3:
  distinct counted points held together by witnessed relations
```

The triangle-like reading is only a projected shadow if triadic closure repeats
and separates from controls. Otherwise it is just a small additive table.

Useful active term:

```text
additive triad closure
```

Parked geometric term:

```text
triangle-like shadow
```

## First Square

Self-relation is present in the first fan. The first nontrivial square
witness appears at `U2`, before the complete additive triad at `U3`.

The degenerate case is:

```text
1 * 1 -> 1
```

This self-relation returns the value `1`. It creates no new value node,
but its witness remains distinct; the return does not authenticate its
assumptions or confer immediate certainty.

The first nontrivial square emergence is:

```text
2 * 2 -> 4
```

Modulus of One reading:

```text
4 through counting spine:
  already-recorded value becomes confirmed at U4

2*2 -> 4:
  square branch witnesses 4

n*n:
  repeated self-relation branch

square-like form:
  geometric shadow of the stable self-relation branch
```

## Guardrails

Do not confuse these:

```text
successor path:
  1 -> 2 -> 3

additive triad:
  1,2,3 with additive and return witnesses

geometric triangle:
  requires additional structure such as incidence, non-collinearity, plane,
  side/edge distinction, area, or orientation
```

Similarly:

```text
span:
  Modulus of One-native relation between two emerged points

line-like shadow:
  projected reading of repeated span / adjacency

Euclidean line:
  not currently defined by Modulus of One
```

## Controls For Triad Language

The triad language is too loose if it cannot separate `1,2,3` from nearby
controls:

```text
1,2,4:
  three points, but no 1+2 -> 4 closure

2,3,4:
  adjacent points, but not first emergence and not closed by 2+3

1,3,4:
  additive closure exists, but first adjacency is skipped

2,3,5:
  additive relation exists, but belongs to a later recurrence pattern
```

Kill rule:

```text
If the witness requirement can be replaced by value equality, the result is not
Modulus of One-native.
```
