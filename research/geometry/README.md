# Geometry Research

> Domain status: active external analysis layer with three implemented program
> families and scoped conceptual leads.

Geometry is not a Modulus of One runtime domain. Geometric names are projections or
constraints applied after rational construction structure has been recorded.
The graph remains the evidence-bearing object.

## Shared Guardrails

- Exact rational identities are not automatically graph-native branch results.
- Co-presence is weaker than a retained construction lineage.
- A quotient or metric defined outside the runtime does not become a runtime
  operation because it is exact.
- Shape language requires an explicit projection rule and the
  [Order-4 evidence standard](../../docs/protocols/order4-projection.md).
- Negative results stay with the program that produced them.
